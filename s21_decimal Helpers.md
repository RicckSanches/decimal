# s21_decimal Helpers

Этот модуль предоставляет функции для работы с типами `s21_decimal` (128 бит) и `s21_big_decimal` (256 бит).
Функции позволяют безопасно управлять **битами мантиссы**, а также получать и устанавливать **знак** и **scale**.

---

## Структура данных

### s21_decimal (128 бит)

| Слова   | Назначение                                                                                                                                           |
| ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| bits[0] | Младшие 32 бита мантиссы                                                                                                                             |
| bits[1] | Средние 32 бита мантиссы                                                                                                                             |
| bits[2] | Старшие 32 бита мантиссы                                                                                                                             |
| bits[3] | Метаданные: <br>Биты 0..15 — не используются (0)<br>Биты 16..23 — scale (0..28)<br>Биты 24..30 — не используются (0)<br>Бит 31 — знак (0 = +, 1 = -) |

### s21_big_decimal (256 бит)

| Слова      | Назначение                                          |
| ---------- | --------------------------------------------------- |
| bits[0..6] | 224 бита мантиссы                                   |
| bits[7]    | Метаданные: знак и scale (аналогично `s21_decimal`) |

> ⚠️ Все функции манипулируют мантиссой и метаданными отдельно. Мантисса всегда располагается в первых `size_in_bits - 32` битах.

---

## Таблица функций

| Функция                                                                | Аргументы                                                                         | Описание                                                       |
| ---------------------------------------------------------------------- | --------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| `int get_bit(const uint32_t *bits, int size_in_bits, int index)`       | `bits` — массив слов, `size_in_bits` — 128 или 256, `index` — номер бита мантиссы | Получает бит мантиссы. Игнорирует старшее слово.               |
| `void set_bit(uint32_t *bits, int size_in_bits, int index, int value)` | `value` — 0 или 1                                                                 | Устанавливает бит мантиссы. Старшее слово не трогается.        |
| `int get_sign(const uint32_t *bits, int size_in_bits)`                 |                                                                                   | Получает знак (0 = +, 1 = -) из старшего слова.                |
| `void set_sign(uint32_t *bits, int size_in_bits, int sign)`            | `sign` — 0 или 1                                                                  | Устанавливает знак в старшем слове.                            |
| `int get_scale(const uint32_t *bits, int size_in_bits)`                |                                                                                   | Получает scale (0..28) из старшего слова.                      |
| `void set_scale(uint32_t *bits, int size_in_bits, int scale)`          | `scale` — 0..28                                                                   | Устанавливает scale в старшем слове.                           |
| `void clear_decimal_bits(uint32_t *bits, int size_in_bits)`            |                                                                                   | Обнуляет все биты мантиссы. Старшее слово остается нетронутым. |

## Примеры использования

### Работа с битами

```c
#include "../s21_decimal.h"

s21_decimal d = {{0}};

// Установим 0-й и 64-й биты мантиссы
set_bit(d.bits, 128, 0, 1);
set_bit(d.bits, 128, 64, 1);

// Проверим значение
int bit0 = get_bit(d.bits, 128, 0);  // 1
int bit64 = get_bit(d.bits, 128, 64); // 1
```

### Работа со знаком

```c
set_sign(d.bits, 128, 1);       // делаем число отрицательным
int sign = get_sign(d.bits, 128); // sign = 1
```

### Работа с scale

```c
set_scale(d.bits, 128, 5);        // scale = 5
int scale = get_scale(d.bits, 128); // scale = 5
```

### Очистка мантиссы

```c
clear_decimal_bits(d.bits, 128); // обнуляет bits[0..2], сохраняет знак и scale
```

### Пример для s21_big_decimal

```c
s21_big_decimal bd = {{0}};

set_bit(bd.bits, 256, 0, 1);    // бит мантиссы
set_bit(bd.bits, 256, 223, 1);  // последний бит мантиссы

set_sign(bd.bits, 256, 1);      // знак
set_scale(bd.bits, 256, 28);    // scale

clear_decimal_bits(bd.bits, 256); // очищаем мантиссу, знак/scale сохраняются
```
