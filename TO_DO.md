## Общая схема работы

1. **Конвертация `decimal` → `big_decimal`**
   - Использовать `decimal_to_big_decimal` для безопасной работы с 224-битной мантиссой.
   - Пример:
     ```c
     s21_big_decimal a, b;
     decimal_to_big_decimal(&value_1, &a);
     decimal_to_big_decimal(&value_2, &b);
     ```

2. **Нормализация scale**
   - Для сложения и вычитания: `normalize_big_decimals(&a, &b)`.
   - Для умножения и деления:
     - Умножение: `scale_res = scale_a + scale_b`
     - Деление: `scale_res = scale_a - scale_b` (с корректировкой для точности)

3. **Основная арифметическая операция**
   - **ADD/SUB**: поразрядное сложение/вычитание с учетом `carry` / `borrow`.
   - **MUL**: аккумулирование всех частичных произведений на 224-битной мантиссе.
   - **DIV**: деление с остатком, накопление результата и округление.
   - Проверка переполнений и корректировка знака.

4. **Конвертация big_decimal → decimal**
   - Использовать `big_decimal_to_decimal`.
   - Производится банковское округление и корректировка scale.
   - Пример:
     ```c
     s21_decimal result;
     big_decimal_to_decimal(&res, &result);
     ```

## Схема работы арифметических операций

```
  ┌───────────────┐
  │  s21_decimal  │
  │  value_1      │
  └───────┬───────┘
          │ decimal_to_big_decimal
          ▼
  ┌───────────────┐
  │ s21_big_decimal│
  │      a         │
  └───────────────┘

  ┌───────────────┐
  │  s21_decimal  │
  │  value_2      │
  └───────┬───────┘
          │ decimal_to_big_decimal
          ▼
  ┌───────────────┐
  │ s21_big_decimal│
  │      b         │
  └───────────────┘

          │ normalize_big_decimals (для ADD/SUB)
          ▼

  ┌─────────────────────────┐
  │ Основная арифметика      │
  │ a + b, a - b, a * b,    │
  │ a / b                    │
  └───────────────┬─────────┘
                  │
                  ▼
        ┌─────────────────┐
        │ s21_big_decimal │
        │   результат     │
        └─────────────────┘
                  │
                  │ big_decimal_to_decimal
                  ▼
        ┌─────────────────┐
        │  s21_decimal    │
        │   результат     │
        └─────────────────┘
```

### Пояснение шагов:

1. **decimal → big_decimal**  
   - Конвертация 96-битной мантиссы в 224-битную для безопасных операций.

2. **Нормализация scale**  
   - Для ADD/SUB: выравниваем scale, чтобы сложение/вычитание прошло корректно.
   - Для MUL/DIV: масштаб корректируется по формуле `scale_res = scale_a ± scale_b`.

3. **Основная арифметическая операция**  
   - Выполняется на `big_decimal` (224-битная мантисса), чтобы избежать переполнений.
   - Для сложения/вычитания: учитывается `carry/borrow`.
   - Для умножения: аккумулируются частичные произведения.
   - Для деления: деление с остатком, точность до 28 знаков.

4. **big_decimal → decimal**  
   - Преобразуем обратно в 96-битную мантиссу.
   - Применяется банковское округление (`bank_round`) и проверка scale ≤ 28.
   - Результат записывается в `s21_decimal`.
